# Польська для пошуку квартири 🏠🇵🇱

Міні-курс із 7 уроків польської для пошуку й оренди квартири — для україномовних (рівень A2).
Статичний сайт без збірки: відкривається у будь-якому браузері, працює з телефону.

**Живий сайт:** https://ap-arto.github.io/pl-lessons/

## Що всередині

| | |
|---|---|
| `index.html` | Головна сторінка курсу зі списком уроків |
| `lessons/0001…0007-*.html` | 7 уроків (лексика, питання, числа, дати, розуміння, потреби, рольова гра) |
| `reference/karta-ratunkowa.html` | Друкована картка-рятівник для дзвінка (A4 + телефон) |
| `assets/style.css` | Спільні стилі |
| `assets/quiz.js` | Інтерактивний квіз (vanilla JS, без залежностей) |

## Локальний перегляд

Просто відкрий `index.html` у браузері — збірка не потрібна.

## Публікація (GitHub Pages)

Сайт статичний і використовує **відносні** посилання, тож працює під підшляхом проєкту
(`https://<user>.github.io/<repo>/`) без жодних переписувань. У корені лежить `.nojekyll`,
щоб Pages віддавав файли як є.

Курс згенеровано як самодостатній HTML. Метадані автора (`MISSION.md`, `NOTES.md` тощо)
